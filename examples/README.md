# Examples — 산출물 구조 예시

실제 분석 결과물이 어떤 형태로 생성되는지 보여주는 샘플입니다.
실제 분석 데이터는 `workspace/` 디렉토리에 저장되며 gitignore 처리됩니다.

## 디렉토리 구조

```
examples/
├── research-sample/     # 학술연구 산출물 구조 예시
├── sector-sample/       # 섹터 분석 리포트 구조 예시
└── company-sample/      # 기업 분석 리포트 구조 예시
```

실제 워크플로우는 `CLAUDE.md`와 `.claude/commands/` 참고.
